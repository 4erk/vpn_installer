# VPN Installer

VPN Installer устанавливает и настраивает VPN на одном или двух серверах под твоим управлением. Соединение устройства с сервером шифруется; в двойной схеме шифруется и связь между серверами.

```text
один сервер (single): устройство -> выбранный сервер -> интернет

два сервера (dual): устройство -> российский сервер -> выбор по правилам
                                                   -> интернет напрямую
                                                   -> зарубежный сервер -> интернет
```

В одиночной схеме разрешённый правилами трафик выходит в интернет через выбранный сервер. В двойной схеме устройство подключается к российскому серверу, а выход в интернет выполняется через российский или зарубежный сервер. Выбор зависит от правил для доменов и IP-адресов; администратор может добавлять свои правила. На устройстве в обоих случаях используется один основной профиль `VLESS/Reality`.

В примерах `home-vpn` — имя установки. При первом запуске оно уже предложено: нажми `Enter` или введи своё имя.

## Что потребуется

- один виртуальный сервер (VPS) с архитектурой `x86_64`, системой запуска служб `systemd`, публичным IPv4 и открытым портом `443` для TCP и UDP для одиночной схемы;
- российский и зарубежный серверы для двойной схемы; устройства подключаются к российскому серверу, а необходимые порты на обоих серверах перечислены в [требованиях к серверам](./docs/PROVIDERS.md);
- серверная ОС из [поддерживаемой матрицы Linux](./docs/PLATFORMS.md): Ubuntu 22.04/24.04/26.04, Debian 12/13, AlmaLinux или Rocky Linux 9/10, Fedora 43/44;
- SSH-доступ под `root` либо пользователем с `sudo`;
- отключённые `ufw` и `firewalld`: установщик создаёт собственные правила сетевого экрана через `nftables`, но не отключает и не перенастраивает другие программы управления сетевым экраном;
- VPN-клиент с поддержкой `VLESS/Reality` и `XTLS Vision`.

Подробности для каждой схемы: [требования к серверам](./docs/PROVIDERS.md).

Совместимые клиенты:

- Windows, Linux и macOS: [Happ](https://www.happ.su/main), [Hiddify](https://hiddify.com/) или [v2rayN](https://github.com/2dust/v2rayN);
- Android: Happ, Hiddify, [v2rayNG](https://github.com/2dust/v2rayNG) или [NekoBox](https://github.com/MatsuriDayo/NekoBoxForAndroid);
- iPhone и iPad: Happ, Hiddify, [Streisand](https://apps.apple.com/app/streisand/id6450534064) или [Shadowrocket](https://apps.apple.com/app/shadowrocket/id932747118).

## Установка через меню

Для установки и повседневной работы запускай интерактивное меню. Отдельные команды нужны для автоматизации и диагностики.

Чтобы получить папку проекта, на странице репозитория в GitHub выбери `Code` -> `Download ZIP` и распакуй скачанный архив. Перейди в распакованную папку, где находятся `vpn.cmd` и `vpn.sh`, затем выполни инструкцию для своей системы ниже.

### Windows

Открой PowerShell в каталоге проекта:

```powershell
.\vpn.cmd
```

### Linux

Открой терминал в каталоге проекта:

```bash
chmod +x ./vpn.sh
./vpn.sh
```

Выбери `Установить или обновить VPN`. Мастер последовательно спросит:

1. Имя установки и схему из одного или двух серверов.
2. IP-адреса и SSH-параметры серверов.
3. Способ входа: пароль (`SSH password`) или ключ (`SSH key`). Пароль показан первым.
4. Нужно ли сохранить введённый пароль после успешной SSH-проверки.
5. Какие узлы установить или обновить.

Пароль никогда не записывается в `deployments`, `state`, логи или Git. На Windows он может быть сохранён в Диспетчере учётных данных текущего пользователя. На Linux используется системное хранилище Secret Service при наличии `secret-tool`. Если оно недоступно, пароль в файл не сохраняется.

Текущая версия видна в заголовке меню. Проверить её отдельно:

```powershell
.\vpn.cmd --version
```

```bash
./vpn.sh --version
```

## Подключение устройства

После успешной установки установщик пытается скопировать ссылку для подключения (URI) в буфер обмена. Если не удалось, ссылка остаётся в файле `vless-uri.txt` на компьютере:

Windows:

```text
out\home-vpn\client\vless-uri.txt
```

Linux:

```text
out/home-vpn/client/vless-uri.txt
```

1. Импортируй `vless-uri.txt` в VPN-клиент. Это основной файл подключения для обеих схем.
2. JSON-файлы из того же каталога используй только если клиент не умеет импортировать URI.
3. `hysteria2-uri.txt` содержит дополнительный профиль Hysteria2 на основе QUIC; он не заменяет основную ссылку VLESS.
4. Инструкции конкретной установки находятся в `NEXT-STEPS.txt` рядом с каталогом `client`.

## Работа через интерфейс

Запускай `.\vpn.cmd` на Windows или `./vpn.sh` на Linux без аргументов. Из меню доступны:

- установка и обновление;
- проверка состояния;
- вывод адреса веб-панели;
- переустановка и удаление серверной части;
- локальная очистка и самопроверка.

Команды нужны для автоматизации и точечной диагностики. Их полный список, влияние на сервер и примеры для обеих ОС: [справочник команд](./docs/COMMANDS.md).

## Веб-панель

Веб-панель устанавливается только в двойной схеме. Её адрес печатается сразу после установки и доступен через пункт `Показать адрес web-admin` в главном меню.

Начальные данные входа: `user` / `password`. Сразу измени их на странице `Доступ`.

В панели можно выбрать, через какой сервер идут запросы к отдельному домену. Например, если твой сервис принимает запросы только с заранее указанных IP-адресов, для него можно выбрать сервер с разрешённым адресом. Правила действуют для всех подключённых устройств; заново импортировать профиль не нужно.

Подробнее: [веб-панель и правила маршрутизации](./docs/ADMIN.md).

## Если что-то не работает

Сначала открой меню и выбери `Проверить текущее состояние`. Интерфейс выводит краткую причину, а технические подробности записывает в файлы.

Windows:

```text
out\logs\runtime\latest-error.log
out\logs\runtime\latest-transcript.log
out\diagnostics\
```

Linux:

```text
out/logs/runtime/latest-error.log
out/logs/runtime/latest-transcript.log
out/diagnostics/
```

Для проверки подключения через основной профиль VLESS используй `verify live` из [справочника команд](./docs/COMMANDS.md). Команда `status` показывает состояние сервера, но сама не проверяет прохождение такого соединения.

## Свойства двойной схемы

- **Один профиль.** Устройство подключается к российскому серверу, а выход в интернет выбирают серверные правила.
- **Два выхода.** Если выбранный правилами выход недоступен, трафик не перенаправляется через другой сервер вопреки этим правилам.
- **Неизменная ссылка подключения.** Обслуживание связи между серверами не требует менять основной URI на устройствах.
- **Раздельные роли.** Российский сервер принимает подключения и выбирает маршрут, зарубежный обеспечивает второй выход в интернет.
- **Резервная связь между серверами.** Постоянный внутренний туннель WireGuard может передавать пакеты через отдельное соединение WireGuard или Hysteria2. Система проверяет эти соединения перед переключением; внутренний туннель и профиль устройства не меняются. Оба соединения ведут на один зарубежный сервер и не заменяют его при отказе.
- **Управление.** Настройки, диагностика и правила находятся на твоих серверах.

Устройство туннелей и порядок проверок описаны в [технической документации](./docs/PROJECT.md).
