# VPN Installer

VPN Installer разворачивает личный VPN на одном или двух серверах:

```text
один сервер: устройство -> VPN-шлюз -> интернет
два сервера: устройство -> российский VPN-шлюз -> зарубежный выход -> интернет
```

В одиночной схеме весь трафик выходит через выбранный сервер. В двойной российские ресурсы используют российский IP, а остальной трафик — зарубежный. На клиенте в обоих случаях используется один основной профиль `VLESS/Reality`; маршрутизация выполняется серверами.

В примерах `home-vpn` — имя установки. При первом запуске оно уже предложено: нажми `Enter` или введи своё имя.

## Что потребуется

- один VPS с Ubuntu 24.04, публичным IPv4 и доступными TCP/UDP `443` для одиночной схемы;
- российский и зарубежный VPS с теми же требованиями для двойной схемы;
- SSH-доступ под `root` либо пользователем с `sudo`;
- VPN-клиент с поддержкой `VLESS/Reality` и `XTLS Vision`.

Проверенные провайдеры:

- российский сервер: [FirstByte](https://firstbyte.pro/?from=242253);
- зарубежный сервер: [iHor](https://ihor.online/?from=439652).

Другие варианты и требования: [выбор серверов](./docs/PROVIDERS.md).

Совместимые клиенты:

- Windows, Linux и macOS: [Happ](https://www.happ.su/main), [Hiddify](https://hiddify.com/) или [v2rayN](https://github.com/2dust/v2rayN);
- Android: Happ, Hiddify, [v2rayNG](https://github.com/2dust/v2rayNG) или [NekoBox](https://github.com/MatsuriDayo/NekoBoxForAndroid);
- iPhone и iPad: Happ, Hiddify, [Streisand](https://apps.apple.com/app/streisand/id6450534064) или [Shadowrocket](https://apps.apple.com/app/shadowrocket/id932747118).

## Установка через меню

Интерактивное меню — основной и рекомендуемый способ работы с проектом.

### Windows

Открой PowerShell в каталоге проекта:

```powershell
.\vpn.cmd
```

### Linux

Открой терминал в каталоге проекта:

```bash
chmod +x ./vpn.sh
./vpn.sh
```

Выбери `Установить или обновить VPN`. Мастер последовательно спросит:

1. Имя установки и схему из одного или двух серверов.
2. IP-адреса и SSH-параметры серверов.
3. Способ входа. `SSH password` показан первым; `SSH key` остаётся отдельным вариантом.
4. Нужно ли сохранить введённый пароль после успешной SSH-проверки.
5. Какие узлы установить или обновить.

Пароль никогда не записывается в `deployments`, `state`, логи или Git. На Windows он может быть сохранён в Диспетчере учётных данных текущего пользователя. На Linux используется системный Secret Service при наличии `secret-tool`; небезопасного файлового fallback нет.

Текущая версия видна в заголовке меню. Проверить её отдельно:

```powershell
.\vpn.cmd --version
```

```bash
./vpn.sh --version
```

## Подключение устройства

После успешной установки URI копируется в буфер обмена, а файлы сохраняются локально.

Windows:

```text
out\home-vpn\client\vless-uri.txt
```

Linux:

```text
out/home-vpn/client/vless-uri.txt
```

1. Импортируй `vless-uri.txt` в VPN-клиент. Это основной и обязательный контракт.
2. JSON-файлы из того же каталога используй только если клиент не умеет импортировать URI.
3. `hysteria2-uri.txt` — дополнительный QUIC-профиль, а не замена основного VLESS URI.
4. Инструкции конкретной установки находятся в `NEXT-STEPS.txt` рядом с каталогом `client`.

## Работа через интерфейс

Запускай `.\vpn.cmd` на Windows или `./vpn.sh` на Linux без аргументов. Из меню доступны:

- установка и обновление;
- проверка состояния;
- вывод адреса web-admin;
- переустановка и удаление серверной части;
- локальная очистка и самопроверка.

Команды нужны для автоматизации и точечной диагностики. Их полный список, влияние на сервер и примеры для обеих ОС: [справочник команд](./docs/COMMANDS.md).

## Веб-панель

Web-admin устанавливается только в двойной схеме. Его адрес печатается сразу после установки и доступен через пункт `Показать адрес web-admin` в главном меню.

Начальные данные входа: `user` / `password`. Сразу измени их на странице `Доступ`.

Панель позволяет направить отдельный домен через российский или зарубежный выход. Например, российский кинотеатр, банк или государственный сервис можно закрепить за российским IP, а зарубежный сайт — за зарубежным. Правила применяются на сервере ко всем подключённым устройствам; переимпортировать URI не нужно.

Подробнее: [web-admin и правила маршрутизации](./docs/ADMIN.md).

## Если что-то не работает

Сначала открой меню и выбери `Проверить текущее состояние`. Интерфейс выводит краткую причину, а технические подробности записывает в файлы.

Windows:

```text
out\logs\runtime\latest-error.log
out\logs\runtime\latest-transcript.log
out\diagnostics\
```

Linux:

```text
out/logs/runtime/latest-error.log
out/logs/runtime/latest-transcript.log
out/diagnostics/
```

Для полной проверки пользовательского пути используй `verify live` из [справочника команд](./docs/COMMANDS.md). `status` сам по себе не доказывает прохождение публичного VLESS-пути.

## Преимущества двойной схемы

- **Один профиль.** Клиент подключается к российскому gateway, а выбор выхода выполняется на серверах.
- **Два региона одновременно.** Российские сервисы видят российский IP, остальные — зарубежный.
- **Стабильная точка входа.** Обслуживание межсерверного пути не требует менять основной URI на устройствах.
- **Раздельные роли.** Gateway принимает клиентов и маршрутизирует трафик, exit обеспечивает внешний выход.
- **Резервирование межсерверной связи.** Два транспорта восстанавливают overlay без смены клиентского профиля.
- **Собственный контроль.** Конфигурация, диагностика и правила находятся на ваших серверах.
