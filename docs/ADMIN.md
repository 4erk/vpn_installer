# Веб-панель маршрутизации

Веб-панель меняет серверные правила маршрутизации без редактирования клиентских профилей. Правила действуют для всех устройств, подключённых к этой установке VPN.

В примерах `home-vpn` — имя установки. Замени его, если при создании было выбрано другое имя.

## Доступ

1. Подключись к VPN.
2. Открой `http://<ip-российского-сервера>:11333`.
3. Войди с начальным логином `user` и паролем `password`.
4. Сразу задай собственные данные на странице `Доступ`.

## Когда добавлять правило

| Ситуация | Выход |
| --- | --- |
| Российский онлайн-кинотеатр не воспроизводит видео с зарубежного IP | `российский сервер` |
| Банк, государственный сервис, маркетплейс, доставка или локальное медиа требует российский IP | `российский сервер` |
| Зарубежный сайт или API недоступен через российский выход | `зарубежный сервер` |
| Отдельный домен сервиса открывается только с нужного региона | Выход этого региона |

Добавляй правило только для проблемного сервиса. Оно переопределяет автоматическую маршрутизацию и применяется ко всем пользователям этого VPN.

## Форматы правил

- `example.com` — только этот домен;
- `*.example.com` — домен и все его поддомены;
- публичный CIDR, например `8.8.8.8/32` — один адрес или указанная IP-сеть.

Не указывай протокол, путь страницы или параметры запроса. Для адреса `https://video.example.com/watch?id=1` значением правила будет `video.example.com`.

CIDR используй только когда сервис публикует стабильный диапазон адресов. Частный или локальный диапазон панель отклонит. Слишком широкая публичная сеть может затронуть посторонний трафик, поэтому начинай с доменного правила или отдельного `/32`.

## Применение

После сохранения новый конфиг проверяется и применяется на российском сервере. Если запуск не проходит, сервер возвращает предыдущие правила. Клиентский VLESS URI менять или импортировать заново не нужно.

Применение правила перезапускает серверный `sing-box`, поэтому активная загрузка или воспроизведение может кратко переподключиться. Сохраняй правила между важными загрузками, затем заново открой проблемный сервис. Отключать VPN или менять профиль не требуется.

Если главная страница открывается, а видео, изображения или авторизация не работают, сервис может использовать отдельные поддомены. Добавь их явно либо включи поддомены для корневого домена, не расширяя правило на посторонние сети.

## Управление из консоли

Посмотреть правила:

```powershell
.\vpn.cmd routes list --deployment home-vpn
```

Направить домен и его поддомены через российский сервер:

```powershell
.\vpn.cmd routes add --deployment home-vpn --value example.com --outbound direct-ru --include-subdomains
```

Направить домен через зарубежный сервер:

```powershell
.\vpn.cmd routes add --deployment home-vpn --value example.com --outbound to-foreign
```

Удалить правило по идентификатору из `routes list`:

```powershell
.\vpn.cmd routes remove --deployment home-vpn --id <rule-id>
```

На Linux замени `.\vpn.cmd` на `./vpn.sh`.
