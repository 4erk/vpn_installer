# Совместимость версий

## Текущее окно 0.23.0

`0.23.0` поддерживает новую установку, повторную установку той же версии и обновление только с `0.22.8`. Для более старой установки сначала нужен последовательный переход на `0.22.8`; временное расширенное окно этой версии не переносится в новый runtime.

| Формат | `0.22.8` | `0.23.0` |
| --- | --- | --- |
| config/state | `3` | `3` |
| manifest/install-plan | `5` | `5` |
| diagnostics | `6` | `6` |

Manifest `0.23.0` объявляет `installed_min=0.22.8`, `installed_max=0.23.0`. Схемы сохранены. Установочный validator знает точный состав файлов тега `0.22.8`, в котором ещё нет выделенных `server_runtime.py`, `server_lifecycle.py`, `server_transport.py` и `journal_evidence.py`. Все прежние ownership, hashes, binaries и acceptance проверки сохранены; новые bundles обязаны содержать новые модули. Проверяется реальный исходный тег, а не текущий bundle с заменённым номером версии.

Runtime не содержит readers старых schemas или цепочки миграций. Host-owned SSH, APT и system resolver не входят в install plan, managed roots или transaction scope.

## Следующая граница

Общий начальный пароль web-admin удалён для новых установок. Существующий `admin-auth.json` сохраняется: обновление не сбрасывает изменённый пароль. Старый общий пароль нужно сменить через защищённый доступ, описанный в [ADMIN.md](./ADMIN.md). Публичный HTTP-порт сохранён; его шифрование не гарантируется наличием активного VPN.

Неиспользуемый `RU_REALITY_MAX_TIME_DIFFERENCE` удалён из defaults, нового env и интерфейса. При чтении существующего deployment он однократно исключается на входной границе; серверный env его и раньше не получал. Reality handshake не меняется.

В `0.23.1`, после повышения минимальной версии до `0.23.0`, удалить обе переходные ветви: очистку этого env-ключа и инвентарь файлов `0.22.8`. У них нет runtime-реализаций или цепочки миграций.

Каждый следующий несовместимый schema-шаг обязан иметь ровно один явно ограниченный переход с непосредственно предыдущего релиза. Совместимый релиз может сохранить текущие schemas и использовать общий validator без adapter.

## Неподдерживаемая версия

Для любой версии вне текущего окна используй `.\vpn.cmd` на Windows или `./vpn.sh` на Linux из совпадающего Git-тега, выполни доступную там команду `remove`/`purge`, затем сделай fresh install текущей версии. Новый установщик не угадывает ownership неизвестного поколения.

Основной `out/<deployment>/client/vless-uri.txt` этим переходом не меняется.
