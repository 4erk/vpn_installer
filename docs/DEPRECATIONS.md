# Совместимость версий

## Текущее окно 0.23.6

`0.23.6` поддерживает новую установку и обновление в окне `0.23.4`--`0.23.6`. С `0.22.8` сначала установи `0.23.0`, затем последовательно `0.23.1`, `0.23.2`, `0.23.3`, `0.23.4` и `0.23.6`. Кандидат `0.23.5` не прошёл выпуск и не требует промежуточной установки; его Git-тег сохранён для проверки истории.

| Формат | `0.23.4` | `0.23.6` |
| --- | --- | --- |
| config/state | `3` | `3` |
| manifest/install-plan | `5` | `5` |
| diagnostics | `7` | `8` |
| transport state | `17` | `17` |

Manifest объявляет `installed_min=0.23.4`, `installed_max=0.23.6`. Установочные схемы сохранены; версии в этом окне проверяются общим validator. Проверяется реальный исходный тег, а не текущий bundle с заменённым номером версии. Диагностический JSON принимает только schema 8; проверка предыдущего релиза использует временный актуальный collector, не изменяя установленный релиз. В `client_transport` удалены недоказанные `risk`, `multiplexed_flow_count` и `flows`; `multiplex_detected` имеет значение `null`, наблюдения сохраняются в `repeated_endpoints` и `repeated_endpoint_count`. Новых adapters нет.

Runtime не содержит readers старых schemas или цепочки миграций. Host-owned SSH, APT и system resolver не входят в install plan, managed roots или transaction scope.

## Следующая граница

Общий начальный пароль web-admin удалён для новых установок. Существующий `admin-auth.json` сохраняется: обновление не сбрасывает изменённый пароль. Старый общий пароль нужно сменить через защищённый доступ, описанный в [ADMIN.md](./ADMIN.md). Публичный HTTP-порт сохранён; его шифрование не гарантируется наличием активного VPN.

Неиспользуемый `RU_REALITY_MAX_TIME_DIFFERENCE` удалён из defaults, нового env и интерфейса. Версия 0.23.0 убирает его при чтении deployment; 0.23.1 больше не выполняет эту миграцию. Неизвестные входные поля отклоняются обычной валидацией. Reality handshake не меняется.

Обе переходные ветви 0.22.8 удалены в 0.23.1; новых adapters не добавлено.

Каждый следующий несовместимый schema-шаг обязан иметь ровно один явно ограниченный переход с непосредственно предыдущего релиза. Совместимый релиз может сохранить текущие schemas и использовать общий validator без adapter.

## Неподдерживаемая версия

Для любой версии вне текущего окна используй `.\vpn.cmd` на Windows или `./vpn.sh` на Linux из совпадающего Git-тега, выполни доступную там команду `remove`/`purge`, затем сделай fresh install текущей версии. Новый установщик не угадывает ownership неизвестного поколения.

Основной `out/<deployment>/client/vless-uri.txt` этим переходом не меняется.
