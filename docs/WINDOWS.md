# Windows: запуск и диагностика

В примерах `home-vpn` — имя установки. Оно предложено по умолчанию при первой установке; замени его в командах, если было выбрано другое имя.

## Точка входа

Запускай проект из корня репозитория только через `.\vpn.cmd`:

```powershell
.\vpn.cmd
.\vpn.cmd --version
.\vpn.cmd status --deployment home-vpn --node all
.\vpn.cmd verify live --deployment home-vpn
```

`.\vpn.cmd` при необходимости подготавливает отдельную копию Python для проекта, запускает интерфейс и записывает логи. `vpn.ps1` является внутренним скриптом подготовки запуска; пользователю запускать его напрямую не нужно. Пункт `Выход` закрывает только установщик и не останавливает серверный VPN.

Для автоматического запуска без ожидания клавиши после завершения:

```powershell
$env:VPN_NO_PAUSE="1"
.\vpn.cmd status --deployment home-vpn --node all --non-interactive
```

## SSH-доступ

Мастер предлагает два взаимоисключающих режима. Пароль показан первым; выбор ключа доступен вторым пунктом.

### Вход по паролю (`SSH password`)

Пароль обрабатывается внутри установщика без запуска `ssh.exe` и без вывода символов на экран. После успешной SSH-проверки мастер предлагает сохранить пароль в Диспетчере учётных данных Windows. Запись привязана к текущему Windows-пользователю и сочетанию имени пользователя SSH, адреса сервера и порта.

Пароль не сохраняется в `deployments`, `state`, `out`, журнале запуска или Git. Если сохранение не выбрано, он существует только в памяти текущего процесса. Сохранённый пароль автоматически доступен последующим командам как при работе через меню, так и с `--non-interactive`.

Удалить запись вручную можно через `Панель управления -> Диспетчер учётных данных -> Учётные данные Windows`; имя начинается с `vpn-installer:ssh:`.

Для временного использования в автоматических запусках поддерживаются `VPN_GATEWAY_SSH_PASSWORD`, `VPN_EXIT_SSH_PASSWORD` и общий `VPN_SSH_PASSWORD`. Не записывай эти значения в файлы проекта или историю команд терминала.

### Вход по ключу (`SSH key`)

- пустое значение: ключи из службы `ssh-agent` и стандартный поиск ключей OpenSSH;
- `id_ed25519`: стандартный путь `%USERPROFILE%\.ssh\id_ed25519`;
- `C:\Keys\vpn-prod`: полный путь;
- `.\keys\vpn-prod`: явный путь относительно текущего каталога.

В этом режиме разрешён только вход по ключу (`publickey-only`). Установщик не переключается на вход по паролю и не показывает ручной запрос `root@host's password`. Если ключ не принят сервером, интерфейс предлагает исправить параметры или явно выбрать `SSH password`.

Ключи серверов SSH в обоих режимах проверяются по файлу `state/known_hosts`, которым управляет установщик. Если в ранее сохранённых параметрах не указан способ входа (`auth_mode`), мастер спрашивает его заново, а не выбирает автоматически.

## Ошибки и логи

Интерфейс показывает одну краткую причину и путь к логу. Технические детали находятся в:

- `out\logs\runtime\latest-error.log` — последняя ошибка, сообщения об ошибках SSH и сведения о месте сбоя в программе;
- `out\logs\runtime\error-*.log` — архив ошибок Python;
- `out\logs\runtime\error-*-powershell.log` — архив ошибок подготовки запуска;
- `out\logs\runtime\latest-transcript.log` — журнал текущего запуска;
- `out\logs\runtime\latest-console.log` — итог выполнения командного файла CMD;
- `out\logs\runtime\latest-bootstrap.log` — каталог, аргументы и сведения о подготовке запуска.

Подробный вывод `OpenSSH_for_Windows ... debug1` и ручной запрос `root@host's password` означают, что `ssh` был запущен напрямую, использовалась устаревшая копия проекта либо внутренний скрипт. Повтори операцию из актуальной папки проекта через `.\vpn.cmd` и явно выбери способ входа.

## Базовая проверка

```powershell
.\vpn.cmd status --deployment home-vpn --node all
.\vpn.cmd diagnose path --deployment home-vpn
.\vpn.cmd verify live --deployment home-vpn
```

`status` и `diagnose` не меняют VPN-клиент на компьютере. `verify live` создаёт временный клиент для проверки подключения из основного `vless-uri.txt`; эта проверка также не перезапускает установленный на компьютере VPN-клиент.

## Веб-панель

Веб-панель существует только у двойной установки. Адрес печатается после успешной установки. Позже выбери `Показать адрес web-admin` в главном меню либо выполни:

```powershell
.\vpn.cmd admin --deployment home-vpn --open-browser
```

Без `--open-browser` открой напечатанный публичный адрес вручную. Команда только показывает адрес, по запросу открывает его в браузере и не меняет текущий VPN-клиент. Сетевой экран временно разрешает доступ к панели только с внешнего IP-адреса, с которого недавно приходили TCP/UDP-пакеты на порт VPN. Для входа дополнительно нужны логин и пароль панели. В одиночной установке команда сообщит, что веб-панель недоступна для этой схемы.
